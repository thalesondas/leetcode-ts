# LeetCode TS

Soluções de problemas do [LeetCode](https://leetcode.com/) utilizando TypeScript.

O objetivo deste projeto é praticar:

* Lógica de programação
* Estruturas de dados
* Algoritmos
* Complexidade de tempo e espaço
* Reconhecimento de padrões
* Resolução de problemas

A seleção prioriza problemas frequentemente utilizados na preparação para entrevistas técnicas e problemas que ajudam a desenvolver fundamentos de lógica e algoritmos.

# File Naming

Problems are stored using their official LeetCode ID, with zero-padding to three digits so that files remain ordered correctly in the file explorer.

```text
001_two_sum.ts
002_add_two_numbers.ts
003_longest_substring_without_repeating_characters.ts
011_container_with_most_water.ts
020_valid_parentheses.ts
121_best_time_to_buy_and_sell_stock.ts
217_contains_duplicate.ts
704_binary_search.ts
```

The zero-padding is only a file organization convention. The numbers correspond to the official LeetCode problem IDs.

# Goal

The goal is not to memorize solutions.

For each problem, I want to be able to:

1. Understand the problem without looking at the solution.
2. Come up with a brute-force approach.
3. Identify a more efficient approach.
4. Explain why the solution works.
5. Analyze time and space complexity.
6. Implement the solution in TypeScript.
7. Recognize the underlying pattern in similar problems.
